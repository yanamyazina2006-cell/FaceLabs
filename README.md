
# FaceLabs - бьюти-приложение с AR и ИИ

**Роль:** Бизнес- и системный аналитик

## О проекте
Pet-проект "FaceLabs" - мобильное приложение, которое с помощью компьютерного зрения и ИИ становится персональным бьюти-консультантом.В приложении можно примерить маски с декоративной косметикой и подобрать уходовые средства.

Ключевая ценность — избавление от бьюти-неопределённости, экономия времени и денег за счёт персонализированных рекомендаций по уходу за кожей, макияжу и стилю.

## Что сделано
- Провела анализ рынка (объём онлайн-сегмента — 1,11 трлн руб., 61% оборота) и конкурентов (YouCam Makeup, ModiFace, Sephora Virtual Artist), выделила 4 пользовательских сегмента.
- Разработала DFD-диаграмму потоков данных (нотация Гейна-Сарсона).
- Описала ценностное предложение для каждого сегмента, определила границы MVP.
- Сформулировала 10 функциональных требований (AR-примерка, персональные рекомендации, каталог, интеграции, личный кабинет, соцфункции, B2B-аналитика, CMS, DAM, безопасность).
- Спроектировала целевую функциональную архитектуру (микросервисы, БД, внешние интеграции).
